# Blackjack After Hours 1.3.0

Дата: 30 октября 2026 года. Android versionCode: 5; package: `com.afterhours.blackjack`.

## Обновления

- Все 52 карты собраны из утверждённых компонентов Retro Casino и подтверждённых пользователем портретов.
- Новая иконка Блекджек для Android и браузера: чёрно-алая грива, очки, изумрудный фон и золотой орнамент.
- Новая вертикальная иллюстрация и адаптивный стартовый экран. Текст и кнопка отрисовываются интерфейсом и остаются чёткими. Игровые кнопки заблокированы, пока открыт стартовый экран; вход доступен после загрузки ресурсов.
- Иллюстрации, карты и звук работают без интернета.
- Номер Android-версии берётся из package.json, а имя выходного APK вычисляется скриптом сборки.
- Для приватного репозитория Pages выключен по умолчанию. Выпуск Android-релиза не делает сайт публичным.

## Проверки

46 тестов правил, анимации, путей и версий проходят. Производственная сборка и проверка происхождения изображений проходят. В Chrome проверены стартовый экран, переход к столу, раздача и настройки на мобильной и широкой компоновках. В APK проверены версия, подпись и байтовое совпадение всех 52 карт и стартовой иллюстрации с актуальными файлами проекта.

Два инструментальных теста прошли на отдельном Android 16 (API 36) эмуляторе с отключёнными Wi-Fi и мобильной сетью: раздача, диалоги, ставки, возврат и восстановление сохранённого баланса. Первый прогон был прерван обновлением системного WebView; повторный офлайн-прогон завершился успешно.

APK подписан существующим отладочным ключом: это установочная тестовая сборка для личной проверки, а не релиз магазина. Для последующих совместимых обновлений нужно сохранить тот же ключ. Ключ в репозиторий и папку загрузок не включён.

## Получение

Приватный репозиторий: https://github.com/Jawerka/Blackjack-After-Hours

Релиз с APK: https://github.com/Jawerka/Blackjack-After-Hours/releases/tag/v1.3.0

APK и файл со ссылками также сохраняются в указанной пользователем папке `S:\yandex-disk\Загрузки`. Ссылки на приватный репозиторий и релиз открываются только у аккаунтов, которым предоставлен доступ.

Перед первой отправкой старая локальная история сохраняется в `_archive/git-history-before-github.bundle`. В GitHub отправляется новый корневой коммит с проверенным деревом без исторического неподтверждённого превью. Локальный архив, кэши, APK и ключи не входят в Git; APK загружается отдельным файлом релиза.
