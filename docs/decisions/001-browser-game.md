# ADR-001: TypeScript, PixiJS и отдельный DOM-интерфейс

Дата: 2026-10-28. Статус: принято для локальной браузерной реализации.

Проект состоит из иллюстраций, колоды и плана. Основная нагрузка — раскладка двумерных карт, анимация дилера и понятные действия игрока. Пользователь хочет запуск в браузере и возможность менять размеры карт.

Выбраны TypeScript, PixiJS 8 и Vite. PixiJS рисует стол и спрайты; DOM отвечает за кнопки, настройки, модальные окна и доступное описание раздачи. Правила выделены в независимый модуль с тестами. Неизменяемые мастер-изображения хранятся отдельно от runtime-экспорта.

WebAssembly не даёт необходимого этому проекту преимущества. Godot подходит при дальнейшем переходе к полноценному редактору сцен и нативным сборкам, но сейчас добавляет экспорт движка. Полностью DOM-реализация тоже возможна, однако Pixi удобнее для управляемых анимаций карт и дыма.

Виртуальные фишки представлены целыми числами. Шаг ставки 10 делает выплату 3:2 целочисленной. Сохранение выполняется на границе завершённого раунда; восстановление незавершённой игры и защищённая серверная экономика вне текущего объёма.

Девять кадров дилера разрезаются по одинаковой сетке без независимой обрезки alpha. Дым, шуз, карты, фишки и живые надписи — отдельные слои. Уважение reduced motion и остановка рендера при скрытой вкладке обязательны.

Источники: [Pixi Application](https://pixijs.com/8.x/guides/components/application), [Assets](https://pixijs.com/8.x/guides/components/assets), [reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion).
