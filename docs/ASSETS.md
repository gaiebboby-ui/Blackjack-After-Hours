# Актуальные игровые ресурсы

`scripts/prepare-assets.mjs` пересоздаёт `public/game/` из выбранных файлов. Папка содержит только производные ресурсы; ручные изменения в ней будут потеряны.

Игра использует стол `assets/scene/blackjack-table-runtime.webp`, фишку `assets/sprites/bet-token-runtime.png`, рубашку `assets/cards/card-back.png`, 52 изображения из `assets/cards/faces/`, базовый `assets/dealer/v3/frame-0.png` и 16 слоёв `face-*.png`. Остальные frame-файлы оставлены для редактирования и восстановления анимации.

## Дилер

Текущий мастер — `assets/dealer/dealer-animation-rows — копия.png` (9×6 ячеек по 418 px). `python assets/dealer/rebuild-from-redesign.py` восстанавливает кадры и слои из этого листа, используя существующие alpha-маски. Затем из корня проекта выполните `python assets/dealer/integrate-smirk.py`, чтобы вернуть актуальную усмешку из `v3/smirk-generated-source.png`. Требуются Pillow, NumPy и OpenCV. Перед изменением сохраните готовые ресурсы: повторный экспорт заменяет кадры. Скрипты создают локальные резервные копии `before-*`, исключённые из Git.

Исходные версии, старые экспорты и экспериментальные инструменты сохранены в `_archive/` с исходной структурой путей. `v3/animations.json` и `v3/LIP-SMIRK.md` содержат сведения об экспортах; тайминги актуальной игровой анимации определяет `src/dealer-animation.ts`.

## Идентичность приложения

`assets/app-icon-master.png` — исходник иконки; размеры в `public/` и favicon производны от него. Android использует PNG-ресурсы для обычной и адаптивной иконки. Обложка README находится в `docs/media/readme-banner.png` и представляет промо-иллюстрацию, а не скриншот игры.

## Оформление Retro Casino

Все 52 лицевые стороны используют выбранное оформление №3 из выбранного референса Retro Casino (варианты сохранены в `_archive/publication-2026-10-30/assets/cards/design-options/`): мятную бумагу, двойную рамку, золотистые звёзды, лучи и фигурные медальоны. После визуальной проверки процедурные орнаменты заменены пятью отдельно сгенерированными растровыми компонентами в `assets/cards/layers/`:

- `01-paper.png` — непрозрачная мятная бумага с печатной фактурой.
- `02-frame.png` — рамка и звёзды, прозрачные снаружи и внутри.
- `03-number-halo.png` — светлая гравировка для числовых карт.
- `04-ace-halo.png` — золотистый ореол с пустым прозрачным центром для тузов.
- `05-court-medallion.png` — тёмный фигурный медальон для портретов, прозрачный снаружи.

Источники созданы встроенным image_gen по одобренному референсу; полный набор промптов находится в `layers/generation-prompts.json`, размеры, контрольные суммы и порядок композиции — в `layers/manifest.json`. Новая генерация при сборке не требуется. Эти пять файлов являются рабочими исходниками и должны храниться вместе со сборщиком, а не только в архиве.

`retro_style.py` нормализует прозрачные поля и размещает компоненты в координатах 512×716. `build_deck.py:card_layers` собирает каждую карту из пяти слоёв: бумага → центральный декор → знаки масти или портрет → рамка → индекс. Числа, буквы и точное количество знаков масти рисуются программно; к печатным символам применяется слабое воспроизводимое зерно. Все 12 прозрачных портретов сохраняются без перерисовки. Рубашка остаётся отдельным ресурсом.

Для изменения оформления заменяйте соответствующий PNG-слой, для настройки его положения — `retro_style.py`, для компоновки индекса, мастей и портретов — `build_deck.py`. Затем выполните команды пересборки выше. `templates/retro-*.png` — производные общие основы, пересоздаваемые сборщиком; ручное редактирование этих экспортов не меняет колоду.

Версия перед процедурным оформлением сохранена в `_archive/assets/cards/before-retro-casino-2026-10-30/`; версия перед переходом на сгенерированные слои — в `_archive/assets/cards/before-generated-layers-2026-10-30/`. Обзоры автоматически обновляются при сборке: `blackjack-deck-preview.png` (вся колода), `retro-style-preview.png` (три примера), `retro-court-preview.png` (все фигуры), `layer-assembly-preview.png` (пять стадий сборки трёх карт).

## Настройки масштаба, языка и цвета

Новая отметка 120% соответствует прежнему физическому размеру 100%, 85% сохраняет прежний размер. Промежуточные значения распределены линейно. Сохранённый старый масштаб переносится один раз; значения выше прежних 100% ограничиваются новым максимумом 120%.

Автоматический язык: русский только при `navigator.language = ru-RU` (без учёта регистра), английский при любом другом регионе. Настройки позволяют выбрать автоматический режим, русский или английский; ручной выбор сохраняется и применяется сразу.

CRT и отдельные Pixi ColorMatrixFilter удалены. Цвет выбирается между обычным изображением, зелёным оттенком и сепией. Оттенок — один прозрачный слой поверх области иллюстраций; он не добавляет полос, искажения геометрии, blur или промежуточных рендер-целей.

Редактируемые PSD/ORA и инструкции по пересборке описаны в [EDITABLE-ART.md](EDITABLE-ART.md).
