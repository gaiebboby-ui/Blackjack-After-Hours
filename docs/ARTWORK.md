## Проверка при сборке

`docs/artwork-provenance.json` содержит разрешённые файлы, их SHA-256 и основания включения. В нём 126 обязательных изображений и 13 необязательных производных превью/атласов. Необязательные экспорты могут отсутствовать в чистом checkout; рабочие изображения обязательны.

`npm run check:artwork` проверяет новые файлы, изменения контрольных сумм, исчезновение обязательных изображений и внешние изображения в README, документации, HTML и исходниках интерфейса. `npm run assets`, а значит и обычная сборка, запускают эту проверку автоматически. Копии `public/game/` не учитываются отдельно: они каждый раз пересоздаются из разрешённых исходников. `dist/`, Android bundled assets и пакеты зависимостей — производные сборки, не самостоятельные художественные исходники.

После согласованного изменения графики нужно обновить соответствующую запись реестра, контрольную сумму и основание происхождения. Не добавляйте неизвестный файл в список только ради прохождения проверки.

Проверка с временным незарегистрированным изображением подтвердила, что такой файл блокирует сборку. Все 46 тестов и производственная сборка после проверки проходят.

Git хранит старые версии файлов в истории. Перемещение в игнорируемый архив исключает файл из нового дерева и новых пакетов, но не переписывает уже созданные коммиты. При первичной проверке история не очищалась; порядок подготовки первого приватного репозитория описан в дополнении 1.3.0 ниже. Проверка происхождения рисунков также не определяет права на самих персонажей или сторонние торговые обозначения.
