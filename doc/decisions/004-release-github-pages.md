# ADR-004: GitHub Pages из стабильных релизов

Дата: 2026-10-30. Статус: принято для подготовки публикации; удалённый репозиторий пока не подключён.

Игра не использует собственный сервер: Vite создаёт статическую сборку, а сохранения остаются в браузере. GitHub Pages подходит по техническим условиям. Пользователь хочет, чтобы сайт обновлялся при выпуске релиза.

Выбран официальный Actions-конвейер Pages: событие release/published для стабильных релизов, checkout точного тега, тесты, сборка и отправка только dist. Развёртывание из каждого push отклонено: main может содержать изменения, которые ещё не выпускались. Отдельная ветка gh-pages не требуется.

Базовый путь берётся из configure-pages: он поддерживает сайт проекта, корневой сайт и собственный домен. Локальная сборка сохраняет относительную базу, в том числе для Android. Тег vX.Y.Z задаёт версию веб-артефакта; package.json остаётся источником локальной версии. version.json и меню показывают идентичность сборки без перезаписи исходников ботом. Версия Android живёт отдельно.

Права записи Pages и OIDC выдаются только deploy. Обычные проверки PR имеют только чтение исходников. Релизы выполняются последовательно; автоматический деплой проверяет Latest. Ручной запуск по стабильному тегу обеспечивает осознанный откат. Окружение github-pages должно разрешать теги v* и основную ветку для ручного запуска.

46 тестов проверяют правила игры, анимацию, пути и обработку версий. Релизная сборка проверяется в браузере под непустым префиксом. Полная инструкция и официальные источники находятся в GITHUB_PAGES.md.
